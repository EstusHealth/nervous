# Nervous System Lab

An interactive guide to the autonomic nervous system for parents and clinicians, by Estus Health.

- Accelerator and brake basics, a day on the dial, and a live body lab
- Window of tolerance, interoception, a body check-in, regulation menu and co-regulation scripts
- A short practice quiz

## Deploy

Static site, no build step. `index.html` at the root is the whole page.

On Vercel: import this repo, set **Framework Preset** to **Other**, leave the build command empty and the output directory as the root. Every push to `main` deploys.

Local preview: open `index.html` in a browser, or run `npx serve .`.
